# Murdjadjo Cinema — Agent Guidelines & User Preferences

Refer to [AGENTS.md](./AGENTS.md) for the complete rules, prompt handling conventions, and design system specifications.

## Quick Summary
- **User Style**: Atmospheric luxury minimalist, dark base (`#060608`), gold/amber highlights (`amber-500`), clean borders, zero UI clutter.
- **Cursor Rules**: Custom spring cursor with minimal dot and trailing `+ More` pill on public exhibition pages; native OS cursor on `/admin`.
- **Typo Tolerance**: Fast typing (e.g. "work whell" = Works Wheel, "curser" = cursor, "foooter" = footer, "versel" = Vercel). Always understand immediately without pedantic questions.
- **Workflow**: Ensure 0 build errors with `npm run build`, commit, and push to GitHub `main` for Vercel deployment.
